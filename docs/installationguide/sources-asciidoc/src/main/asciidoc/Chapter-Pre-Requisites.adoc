[[_prerequisites]]
= Pre-Requisites

.Installation Pre-Requisites
[cols="1,3", frame="all", options="header"]
|===
| Component | Requirement
| Operating system | Linux, with SCTP support in the kernel. {this-platform} {this-application} is tested on Ubuntu LTS.
| Java | A Java 11 runtime (JRE or JDK) on the `PATH`. The appendix of this guide describes installing one.
| SCTP library | The `lksctp-tools` package, which the Java runtime needs to open SCTP associations.
| Memory | `bin/start.sh` starts the JVM with a 1 GB heap by default: allow for it, plus the operating system.
| Network | The SCTP ports of the M3UA associations in the configuration used, open between {this-application} and the signalling points of both networks.
| Docker | Optional: to run {this-application} in a container, as described in <<_docker>>.
|===
