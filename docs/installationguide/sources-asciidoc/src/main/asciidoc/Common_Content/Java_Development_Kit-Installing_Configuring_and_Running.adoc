= Java: Installing and Choosing the Version

{this-platform} {this-application} runs on Java 11. A runtime (JRE) is enough; a full JDK works too.

== Installing

On Ubuntu or Debian:

[source,bash]
----
sudo apt install openjdk-11-jre-headless
----

On Red Hat Enterprise Linux and its derivatives:

[source,bash]
----
sudo dnf install java-11-openjdk-headless
----

OpenJDK 11 builds from Eclipse Temurin or Amazon Corretto work equally well.

== Checking

[source,bash]
----
java -version
----

The first line of its output should name version 11.

== Choosing between several installed versions

`bin/start.sh` runs the `java` it finds on the `PATH`, so on a host with several Java versions installed, select 11:

[source,bash]
----
sudo update-alternatives --config java
----

`JAVA_HOME` isn't needed.
