[[_installation]]
= Installation

{this-platform} {this-application} is distributed as a single zip, `Naikeri-HRR-<version>.zip`.
Unpack it wherever it should live, for example under `/opt/naikeri/hrr`:

[source,bash]
----
mkdir -p /opt/naikeri/hrr
cd /opt/naikeri/hrr
unzip Naikeri-HRR-<version>.zip
----

There is no installer, and running it needs no root access. The installation directory holds:

[cols="1,3", frame="all", options="header"]
|===
| Directory | Contents
| `bin/` | The {this-application} jar, its dependencies in `lib/`, and `start.sh`
| `conf/` | The two proxy configurations, `map-proxy.xml` and `cap-proxy.xml`, their rules, `map-application-rules.xml` and `cap-application-rules.xml`, and `log4j2.xml`
| `docs/` | The admin guide and this guide, each as an HTML book and a PDF
| `logs/` | Where {this-application} writes its logs and CDRs
|===

A `state/` directory appears beside them at the first start: see <<_running>>.
